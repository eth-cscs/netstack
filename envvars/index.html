    Environment variables¶

    Environment variables are user components. They are as much a part of the netstack as the libraries. They are the most common way to tune the netstack, and the most common source of misconfiguration. This page lists the netstack-relevant variables, grouped by the component that reads them.

    user-stack reports the variables from these families that are currently set. It matches the prefixes MPICH_, FI_, OFI_NCCL_, NCCL_, CXI_, PMI_, PALS_, XPMEM and CUDA_.

    How to read the component field

    A variable often crosses layers. Cray MPICH reads MPICH_GPU_SUPPORT_ENABLED, but the variable has an effect only when cray-gtl is present. FI_MR_CACHE_MONITOR is a libfabric setting. Its correct value depends on the combination of XPMEM and the kernel under it. In the JSON output, each of these appears in envvars as {"name": ..., "value": ..., "component": ...}. See JSON output for details.

    Cray MPICH¶

    Variable Affects Notes
    MPICH_GPU_SUPPORT_ENABLED cray-mpich, cray-gtl 1 enables GPU-aware MPI. An application can then pass GPU pointers to MPI. Requires the GTL library.
    MPICH_GPU_IPC_ENABLED cray-mpich Intra-node GPU-to-GPU transfers through CUDA IPC.
    MPICH_SMP_SINGLE_COPY_MODE cray-mpich, xpmem Intra-node single-copy transport: XPMEM, CMA or NONE.
    MPICH_OFI_NIC_POLICY cray-mpich, libfabric How Cray MPICH assigns ranks to the Slingshot NICs: NUMA, BLOCK or ROUND-ROBIN.
    MPICH_OFI_NIC_VERBOSE cray-mpich Print the NIC-selection decisions.
    MPICH_ENV_DISPLAY cray-mpich Print every MPICH variable and its value at startup.
    MPICH_VERSION_DISPLAY cray-mpich Print the MPICH and GTL version banner at startup.
    MPICH_MEMORY_REPORT cray-mpich Report high-water memory use per rank.

    Open MPI¶

    Users tune Open MPI through OMPI_* variables and MCA parameters, not through MPICH_*. The fabric-level FI_* variables below still apply, because Open MPI reaches Slingshot through the same libfabric cxi provider.

    Variable Affects Notes
    OMPI_MCA_pml openmpi Point-to-point management layer, for example cm for the OFI MTL or ob1 for the BTLs.
    OMPI_MCA_mtl, OMPI_MCA_btl openmpi, libfabric Select the transport. ofi routes traffic over libfabric and CXI.
    OMPI_MCA_opal_cuda_support openmpi, cuda Force CUDA-aware support on or off.

    libfabric¶

    Variable Affects Notes
    FI_PROVIDER libfabric Restrict the provider set, for example to cxi. Leave it unset normally; libfabric then chooses the best provider.
    FI_MR_CACHE_MONITOR libfabric, xpmem Memory-registration cache monitor: memhooks, userfaultfd, kdreg2 or disabled. If it does not match the kernel, it often causes crashes and corruption. It is a common target for diagnosis.
    FI_HMEM libfabric, cuda Enable heterogeneous memory support (GPU memory) in the provider.
    FI_LOG_LEVEL, FI_LOG_PROV libfabric Sets the logging verbosity, and limits logging to one provider such as cxi.

    CXI provider¶

    The CXI provider is the Slingshot 11 back end inside libfabric.

    Variable Affects Notes
    FI_CXI_RX_MATCH_MODE libfabric, libcxi Tag-matching mode: hardware, software or hybrid. If the mode falls back from hardware to software matching under load, performance drops sharply.
    FI_CXI_RDZV_THRESHOLD libfabric Message size at which the rendezvous protocol takes over from eager.
    FI_CXI_RDZV_PROTO libfabric Rendezvous protocol variant, for example default or alt_read.
    FI_CXI_DEFAULT_CQ_SIZE libfabric Completion-queue depth. A value that is too small causes FI_EAGAIN errors and retries in large jobs.
    FI_CXI_REQ_BUF_SIZE, FI_CXI_OFLOW_BUF_SIZE libfabric Size of the unexpected-message and overflow buffers.
    FI_CXI_OPTIMIZED_MRS libfabric, libcxi Use hardware-optimized memory regions.
    FI_CXI_DISABLE_HOST_REGISTER libfabric Prevents registration of host memory with the NIC. Interacts with GPUDirect RDMA.

    aws-ofi-nccl¶

    Variable Affects Notes
    OFI_NCCL_PROTOCOL aws-ofi-nccl Transport protocol that the plugin uses: RDMA or SENDRECV.
    OFI_NCCL_GDR_FLUSH_DISABLE aws-ofi-nccl, cuda Disable the GPUDirect RDMA flush. This affects correctness.
    OFI_NCCL_DISABLE_GDR_REQUIRED_CHECK aws-ofi-nccl Bypass the GPUDirect RDMA support check.
    OFI_NCCL_NIC_DUP_CONNS aws-ofi-nccl Number of duplicate connections per NIC, to increase bandwidth.

    NCCL¶

    Variable Affects Notes
    NCCL_NET_PLUGIN nccl, aws-ofi-nccl Which network plugin NCCL loads. ofi selects aws-ofi-nccl over libfabric and CXI.
    NCCL_NET nccl The transport that NCCL selects, reported as, for example, AWS Libfabric.
    NCCL_DEBUG nccl Logging level: WARN, INFO or TRACE. INFO prints the chosen net plugin and the topology.
    NCCL_DEBUG_SUBSYS nccl Restrict debug output to subsystems such as NET, INIT or COLL.
    NCCL_CROSS_NIC nccl Allow rings and trees to cross NICs.
    NCCL_ALGO, NCCL_PROTO nccl Force a collective algorithm, Ring or Tree, or a protocol, LL, LL128 or Simple.
    NCCL_NVLS_ENABLE nccl Enable NVLink SHARP. This feature reduces data in the network, over NVLink.

    Launcher and PMI¶

    The launcher populates these variables when the job starts. The launcher is either Slurm or cray-pals, through cray-pmi. They describe rank and job identity. Users do not normally set them by hand. user-stack reports them because their presence shows which wire-up path the job uses.

    Variable Affects Notes
    PMI_RANK, PMI_SIZE, PMI_LOCAL_RANK, PMI_LOCAL_SIZE, PMI_UNIVERSE_SIZE cray-pmi Rank identity and topology for the PMI wire-up.
    PMI_CONTROL_PORT, PMI_SHARED_SECRET, PMI_JOBID cray-pmi Control-plane rendezvous for process management.
    PMIX_RANK, PMIX_NAMESPACE, PMIX_SERVER_URI* and the rest of PMIX_* pmix The PMIx equivalent. Open MPI uses it, and the PMIx server of the launcher sets it.
    PALS_RANKID, PALS_NODEID, PALS_APID and the rest of PALS_* cray-pals Per-rank and per-node identity. The PALS launcher sets it.

    CUDA¶

    Variable Affects Notes
    CUDA_VISIBLE_DEVICES cuda, cuda-driver Which GPUs the process sees. This affects GPU-to-NIC affinity.
    CUDA_HOME cuda Toolkit root. The uenv view sets it.
    CUDA_CACHE_PATH cuda Location of the JIT compilation cache.
    CUDA_MODULE_LOADING cuda Module loading mode, EAGER or LAZY.
